# LDSW - Layouts en Flutter

Actividad 3.5. Home screen de CineApp usando layouts de Flutter
(`Stack`, `Column`, `Spacer`, `SafeArea`, `Padding`) y los widgets `Image`, `Icon` y `Text`.

- `lib/home_screen.dart`: pantalla de inicio (imagen de fondo, icono, nombre de la app y mensaje de bienvenida).
- `lib/catalog_screen.dart`: catálogo de la actividad 3.4, accesible con el botón "Ver catálogo".
- `assets/images/fondo.png`: imagen de fondo.

## Cómo ejecutarla

```
flutter create .
flutter pub get
flutter run
```

`flutter create .` genera las carpetas de plataforma (android, ios, web) sin tocar `lib/`.
