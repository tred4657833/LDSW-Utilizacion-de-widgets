# LDSW - Utilizacion de widgets

Actividad 3.4. CineApp (catalogo de peliculas) usando los widgets basicos de Flutter:
`Text`, `Row`, `Column`, `Stack` y `Container`.

## Como ejecutarla

```
flutter create .
flutter pub get
flutter run
```

`flutter create .` genera las carpetas de plataforma (android, ios, web) sin tocar `lib/main.dart`.
